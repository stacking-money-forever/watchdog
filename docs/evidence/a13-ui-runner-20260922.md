# A13 — shipping UI runner 검증 (2026-09-22)

ledger에서 A13은 "fixture 소스·번들은 통과했지만 shipping UI runner는 미검증"으로 남아 있었다.
이번에 실제로 돌려 통과시켰다.

## 블로커의 정체

첫 시도는 실패했고, 그 오류가 원인을 정확히 알려줬다.

```
Failed to initialize for UI testing:
Error Domain=com.apple.LocalAuthentication Code=-2 "Canceled by user."
NSLocalizedDescription=인증이 취소되었습니다.   BiometryType=1
```

Xcode 27 / CoreDevice framework 불일치로 기록돼 있던 것과 달리, 실제 블로커는
**UI 테스트 러너 초기화에 필요한 사용자 인증(Touch ID) 프롬프트**였다. 사용자가 인증한 뒤 같은 명령이 통과했다.

## 실행

```
xcodebuild test -project Watchdog.xcodeproj -scheme Watchdog \
  -destination 'platform=macOS' -derivedDataPath /tmp/wd-ui-dd2 \
  -only-testing:WatchdogUITests
```

결과: `Executed 9 tests, with 0 failures (0 unexpected) in 61.687 seconds` — `** TEST SUCCEEDED **`

통과한 테스트 (shipping `Watchdog` 타깃, DEBUG fixture 사용):

1. `testShippingAppShowsHeaderAndTextualAlertReasons`
2. `testAboutPanelShowsVersionAndCopyright`
3. `testSearchShowsNoMatchState`
4. `testStaleFixtureDisablesControlsAndExplainsWhy`
5. `testAuthoritativeOutcomeWordingDoesNotClaimExit`
6. `testIgnoreShowsRecoveryControl`
7. `testExitedAndStillRunningOutcomeWording`
8. `testTerminateConfirmationCanBeReachedAndCancelledWithoutSendingSignal`
9. `testForceQuitHasSeparateStrongerConfirmationAndCanBeCancelled`

특히 8·9는 실제 앱에서 파괴적 확인창에 **도달하고 취소**하는 경로를 검증한다(신호 전송 없음).

## 실행 후 상태

- 실행이 끝난 뒤 남은 Watchdog 프로세스는 soak 후보(`15912`) 뿐이었다 — 테스트 인스턴스는 러너가 정리했다.
- soak 표본은 계속 정상(`fd 38`, heartbeat 단조 증가)이라 테스트가 soak를 교란하지 않았다.

## 남은 구멍

9개 테스트 중 **"확인창이 popover close/reopen을 견디는지"를 다루는 테스트는 없다.**
A19의 잔여 항목이 그대로 남는 이유이며, 이것은 여전히 사람 관찰이 필요하다.
